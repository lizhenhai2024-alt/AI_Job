## 2. 已核验 2027：迪卡侬中国

### 招聘项目

- 项目：**迪卡侬 2027 秋季招聘**
- 官方校园招聘页：https://recruitment.decathlon.com.cn/p/campus.html
- 官方投递系统：https://wecruit.hotjob.cn/SU64631fe6bef57c0907f133c4/pb/school.html?projectCode=0&showProjectBanner=true
- HotJob tenant：`64631fe6bef57c0907f133c4`
- 申请时间：**2026-09-01 至 2026-11-30**
- 面向人群：官网明确包含 **2027 届应届毕业生**（同时覆盖指定范围内往届毕业生）

### 官网岗位方向

1. 运动部门经理
2. 全渠道运动主管
3. 线上运营主管
4. 生产供应链主管
5. 供应商质量和新产品导入主管
6. 供应链计划主管
7. 物流部门经理

### JD 摘要（对英语专业机会看板更相关的方向）

**线上运营主管**

- 制定品类年度计划与线上运营策略；
- 策划并执行电商活动，优化商品故事、内容与转化；
- 基于销售和业务节奏做库存预测；
- 持续优化商品详情、内容呈现和用户体验。

这类岗位与当前看板的“电商运营 / 内容策略 / 品牌运营”方向高度相邻，应进入候选池后再执行专业硬门槛与经验匹配。

**供应链计划主管**

- 参与业务规划并制定目标；
- 承担全周期预测、采购/布局、价格和毛利管理；
- 进行库存配置与优化。

岗位偏商业计划与供应链分析，英语专业并非天然匹配，必须以具体 JD 的专业要求为准。

**生产供应链主管**

- 根据客户需求和供应商产能制定生产计划；
- 管理订单、交付与库存；
- 提升数据准确性、产能平衡和柔性生产效率；
- 与供应商及内部伙伴协作解决供应链问题。

该岗位业务属性较强，但如具体职位明确要求理工/供应链专业，应按现有硬门槛规则过滤。

### AI_Job 接入

本次已将迪卡侬加入 `config/official-sources.json -> hotjob`。现有 HotJob 抓取器会读取：

- 岗位名称
- 工作地点
- 项目名称 / 2027 证据
- 完整岗位职责
- 任职要求
- 发布时间 / 截止时间
- 英语、数据、运营、供应链等技能信号

然后继续执行仓库现有的：2027 届资格、实习排除、纯销售排除、专业硬门槛、小语种硬门槛及英语专业适配判断。

注意：官网当前页面没有明确写“2027届”，因此 `AI_Job` 不应仅因为项目正在招聘就强行标记 2027。对英语专业而言，官网列出的专业范围也没有明确包含英语专业，最终应由具体职位 JD 决定是否淘汰。
