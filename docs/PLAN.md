# AI Job V1 规划

## 产品目标

面向 2027 届校招场景，先解决一个最重要的问题：**今天有哪些岗位值得我优先投？为什么？**

V1 不追求“自动海投”，而是建立可靠的求职决策闭环：

1. 岗位雷达：聚合岗位并支持筛选、排序、去重扩展。
2. 可解释匹配：基于候选人画像计算 0–100 匹配分，并展示亮点、缺口和风险。
3. 投递看板：收藏、已投递、面试、Offer、淘汰状态持续追踪。
4. 候选人画像：毕业届别、目标岗位、城市、技能、语言、经历关键词、排除条件统一管理。

## 设计原则

- **画像是唯一事实源**：匹配与后续简历定制不得虚构经历。
- **先评估、再投递**：优先级高于“投递数量”。
- **岗位来源可追溯**：正式接入数据源后，必须保留 source/sourceUrl/fetchedAt。
- **数据层可插拔**：官网、CSV、开放数据集、人工录入都映射到同一 Job Schema。
- **默认不自动投递**：任何对外提交动作都由用户确认。

## V1 信息架构

- 岗位雷达：指标卡 + 筛选 + 岗位卡片 + 匹配解释
- 投递看板：按状态分栏
- 我的画像：可编辑结构化偏好

## 匹配模型

V1 使用确定性加权规则，便于测试和解释：

- 岗位方向 28%
- 技能命中 22%
- 城市偏好 12%
- 经历关键词 12%
- 语言要求 10%
- 毕业届别 8%
- 工作偏好/风险 8%

后续可在不改 UI 的前提下，把 `src/core/matcher.js` 替换为 LLM/Embedding + 规则混合模型。
